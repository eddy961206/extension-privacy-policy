Chrome Extensions Privacy Policy

Last updated: May 17, 2026

This privacy policy applies to Chrome extensions published by eddy961206, including Korean Word Lookup, Airplane Chime Timer, Easy Encrypt, and other Chrome extensions that link to this page.

Summary

  • The extensions do not sell personal information.
  • The extensions do not use personal information for credit, lending, employment, or eligibility decisions.
  • Extension settings are stored locally in Chrome storage unless a feature clearly requires an external service.
  • Only the minimum data needed for each feature is processed.

Data Processed by Extension

Extension Data processed Purpose Where it is processed or stored
Korean Word Lookup Selected or hovered text, language/settings preferences, optional KRDICT API key, privacy-safe usage events. Show translations, dictionary definitions, remember preferences, and understand aggregate feature usage. Selected or hovered text may be sent to Google Translate or KRDICT only to return translation or dictionary results. Settings are stored in Chrome storage. Product analytics events are sent to Google Analytics without raw selected text.
Airplane Chime Timer Timer settings, selected sound, volume, custom sound files, usage counters for local review prompts. Run reminder timers, play selected chimes, save preferences, and manage local review prompts. Stored locally in Chrome storage. Custom sounds are stored locally in the browser.
Easy Encrypt Input text, output text, selected algorithm, optional remembered key, usage count, context-menu selected text. Encrypt, decrypt, encode, decode, hash text, copy results, and remember local preferences. Processed locally in Chrome. Secret keys are not saved unless the Remember key option is turned on.

Data Sharing

The extensions do not sell user data and do not share user data with advertisers or data brokers. Korean Word Lookup may send lookup text to Google Translate or KRDICT when the user requests a translation or dictionary result. Korean Word Lookup may send privacy-safe usage events to Google Analytics to measure aggregate product usage; raw lookup text is not included.

Remote Services

  • Google Translate: used by Korean Word Lookup to fetch translation results.
  • KRDICT: used by Korean Word Lookup to fetch Korean dictionary results.
  • Google Analytics: used by Korean Word Lookup for aggregate product analytics without raw lookup text.

Local Storage

The extensions use Chrome storage to save preferences and feature state. This can include settings, timer choices, selected algorithms, optional custom sounds, and optional keys when a user explicitly enables a remember option. Users can clear extension data by removing the extension from Chrome or clearing the extension's site/app data in Chrome.

Security

The extensions use Chrome extension storage and browser APIs to keep processing scoped to the extension features. Easy Encrypt is a convenience tool for local text encryption, encoding, and hashing; users should not treat it as a replacement for a dedicated enterprise password manager or audited security system.

Children

These extensions are general productivity tools and are not directed to children under 13.

Changes

This policy may be updated when extensions add, remove, or change data processing behavior. The date at the top of this page will be updated when material changes are made.
