Chrome Extensions Privacy Policy

Last updated: November 6, 2026 (2026-11-06)

This privacy policy applies to Chrome extensions published by eddy961206, including Korean Word Lookup, Airplane Chime Timer, Easy Encrypt, and other Chrome extensions that link to this page.

Summary

  • The extensions do not sell personal information.
  • The extensions do not use personal information for credit, lending, employment, or eligibility decisions.
  • Storage depends on the extension. Korean Word Lookup 2.6.0 uses Chrome sync for ordinary settings, local storage for counters and diagnostics, and memory-only session storage for the KRDICT key.
  • Only the minimum data needed for each feature is processed.

Korean Word Lookup 2.6.0

This section describes version 2.6.0. Until your installed extension is updated, the older-version notice below applies. The version number identifies the behavior described here; this policy's date does not mean that every browser has received the update.

Translation requests and controls

When translation is enabled and the current site is not paused, hovering over a Korean word sends that word to the selected provider. In Alt / Option + hover mode the modifier key must be held. Providers: Google Translate (translate.googleapis.com) or the National Institute of Korean Language's KRDICT (krdict.korean.go.kr). If automatic source fallback is enabled and a lookup fails, the word may also be sent to the other provider. KRDICT requests require your own API key.

Selection translation is off by default. When enabled, selecting Korean text of up to 500 characters sends the selection to Google for English or Vietnamese translation in the selected result language, even when KRDICT is selected for word lookups. With selection translation enabled, Alt / Option + Enter explicitly looks up the selection and pins and focuses its result. This shortcut still respects translation-off, paused-site, and editable-field protections. The extension does not upload the whole page. Mouse and selection events are processed locally to operate these features. Input/password fields, textareas, editable regions, and selections crossing editable content are skipped, but other page text may still be private.

Turn translation off in the popup or with its configured keyboard shortcut before reading text you do not want a provider to receive. Selection translation and automatic source fallback have separate controls. An optional browser on-device fallback, when supported, is attempted only after a Google request fails; it does not make the initial request offline.

Provider requests use HTTPS and omit browser cookies and the page referrer. The extension does not attach the browsing page's URL. Providers receive the lookup text and normal network metadata, including your IP address. KRDICT also receives your API key. Provider availability, processing, and retention are governed by those providers; we do not promise a provider-side deletion period.

KRDICT key and settings

Version 2.6.0 keeps your KRDICT API key in Chrome extension session storage, in memory, accessible only to trusted extension contexts. Newly entered keys are not saved to persistent local storage or Chrome sync. The key is sent only to KRDICT for dictionary requests, never to Google or page content scripts. The popup shows whether a key exists, not the stored key itself. Use Save key to replace it or Clear key to remove it. Enter it again after a browser restart or after the extension is reloaded, disabled, or updated, because these actions clear session storage.

During upgrade, an existing key in legacy local or sync storage is transferred to session storage. Legacy stored values are removed only after that transfer succeeds; a failed transfer can leave the old values in place. Older versions on other browsers or devices can retain their previous storage behavior until updated. This migration cannot undo copies previously synchronized to other devices.

Ordinary preferences, including translation enablement, source selection, and tooltip settings, use Chrome sync storage. Chrome may synchronize those preferences across browsers when browser sync is enabled.

User-authored notebook and paused sites

The notebook stores words only after you explicitly save them, plus meanings, notes, and context you write yourself. Saving a lookup passes the source word only; Google and KRDICT results are not automatically saved or prefilled. No surrounding paragraph, page URL, title, or automatic lookup history is added. Notebook data stays in this Chrome profile's local extension storage, is not encrypted, and is not a private vault. It is not synchronized to other devices or uploaded to a server.

The notebook is limited to 2,000 entries and a 2 MB data budget. The last 20 deleted entries remain locally recoverable through Undo. Older recovery copies are removed as more entries are deleted. CSV/TSV exports and JSON backups contain all saved entries and user notes, including entries hidden by search. Exported files are separate copies you control. JSON import validates a backup up to 2 MB, asks for confirmation, and adds new entries without replacing existing terms or identifiers. Removing the extension removes local notebook data but not exported files.

Site pause stores only the hostname that you explicitly choose to pause, up to 500 hostnames, in local extension storage. It does not store page paths, query strings, titles, or visit times. Resume a site or resume all paused sites to remove those preferences. New provider requests check the pause state; requests already sent cannot be retracted.

Copy writes a displayed result to your clipboard only when you click Copy, with source attribution. KRDICT text is attributed to the National Institute of Korean Language under CC BY-SA 2.0 Korea. The extension's own code license does not replace the provider's data license.

Local counters, diagnostics, and temporary results

Version 2.6.0 has no remote product-analytics sender. Usage events, analytics identifiers, lookup text, and browsing history are not uploaded as analytics. Translation requests described above are separate from analytics.

Local counters and dates support onboarding and review prompts, including installation and first-success state, word/selection usage counts, and prompt preferences. These can remain for the installation lifetime. Recent diagnostics contain event timestamps, fixed event names, enum categories, and bounded counters, not lookup words, page URLs, API keys, free-form error messages, or provider results.

The diagnostic event trail is limited to 200 entries. Events and daily diagnostic buckets older than 30 days are removed when the next event is recorded; there is no timed deletion while the extension is idle. This retention limit does not apply to the installation-lifetime counters described above.

Translation results are cached temporarily in each page's content-script memory, up to 200 entries, with a 24-hour expiration checked on lookup. Reloading or closing the page clears that page's cache. Results are not written to persistent extension storage. Removing the extension removes its local extension data through Chrome. Opening feedback opens a GitHub issue form and does not submit anything automatically. Do not post API keys, private text, private URLs, or personal data in public feedback.

Older versions

Version 2.5.2 and earlier may send product usage events to Google Analytics without raw lookup text, and may retain the KRDICT key in persistent Chrome storage, including sync storage. Version 2.5.3 removed the remote analytics sender and legacy analytics settings and identifiers. Updating does not delete records that an older version may already have sent to Google Analytics or another independently configured service. Older versions can continue their previous behavior until updated.

Data Sharing

The extensions do not sell user data and do not share user data with advertisers or data brokers. Korean Word Lookup shares lookup text with its translation and dictionary providers to return results, as described above. Version 2.6.0 does not send remote product analytics; version 2.5.2 and earlier may have sent Google Analytics events.

Remote Services

  • Google Translate: used by Korean Word Lookup for translation requests, including enabled selection translation.
  • KRDICT: used by Korean Word Lookup for dictionary requests with the user's API key.
  • Chrome sync: may synchronize Korean Word Lookup's ordinary preferences when browser sync is enabled.
  • Google Analytics: used by Korean Word Lookup 2.5.2 and earlier for product usage analytics, not by versions 2.5.3 or 2.6.0.
  • GitHub: hosts the feedback form opened by Korean Word Lookup; submitting feedback is a separate user action.

Storage for Other Extensions

Airplane Chime Timer stores timer choices, sounds, volume, custom sound files, and review-prompt counters locally as described in the table. Easy Encrypt processes text locally and stores its preferences and an optional remembered key as described in the table. Users can clear extension data by removing the extension from Chrome or clearing the extension's site/app data in Chrome.

Security

The extensions use Chrome extension storage and browser APIs to keep processing scoped to the extension features. Easy Encrypt is a convenience tool for local text encryption, encoding, and hashing; users should not treat it as a replacement for a dedicated enterprise password manager or audited security system.

Children

These extensions are general productivity tools and are not directed to children under 13.
